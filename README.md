# 시리 토익 (비공개 배포판)

폰 홈 화면에 추가해서 앱처럼 쓰는 단어장. 비밀번호를 아는 사람만 내용을 볼 수 있다.

## 접근 제한 방식
- 단어·뜻·예문은 `docs/words.enc.json`에 **AES-256-GCM으로 암호화**되어 있다 (PBKDF2-SHA256 31만 회).
- 페이지 주소를 알아도 비밀번호가 없으면 잠금 화면만 보인다. 비밀번호는 저장소에 없다.
- 평문 원본(`data/`)은 `.gitignore`로 제외되어 GitHub에 올라가지 않는다. **로컬에만 보관하고 따로 백업할 것.**
- 한계: 비밀번호를 공유받은 사람은 볼 수 있고, 약한 비밀번호는 오프라인 대입 공격에 취약하다. 길고 무작위인 비밀번호를 쓸 것.

## 비밀번호 바꾸기 / 내용 수정
```
# data/*.json 수정 후
PASSCODE='새비밀번호' node scripts/build_secure.mjs
git add docs && git commit -m "update" && git push
```
(바꾸면 이미 로그인한 기기는 다시 비밀번호를 물어본다.)

## 배포 (GitHub Pages)
저장소 Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, Folder: `/docs`.
주소: `https://<계정>.github.io/<저장소>/`

## 폰에 앱처럼 설치
- iPhone: Safari로 열기 → 공유 → 홈 화면에 추가
- Android: Chrome → 메뉴 → 홈 화면에 추가 / 앱 설치

## 기능
- 모바일 최적화(세이프에어리어, 큰 터치 영역, 카드 좌우 스와이프, 오프라인 캐시)
- 화면 모드: 자동 / 라이트 / 다크 (상단 ◐ 버튼)
- 예문: 토익 예문 + **시리의 일상 예문** (끔 / 토익 / 시리 / 둘 다)
- 25단어씩 세트(48세트), 단어 옆 미국식 발음기호(IPA)
- 기존 기능 유지: 블라인드, 발음, 목록·카드, 외움 체크, 섞기
